Feedback

The meter’s panel has a Send feedback button. It POSTs a small JSON body to the relay URL below, which is expected to forward it to Discord. Leave it empty to hide the button.

Put a relay URL here, not a Discord webhook. A webhook URL stored in an extension is readable by anyone who installs it, and rotating it would mean shipping a new release. A relay you control keeps the webhook server-side and lets you rate-limit or filter before anything reaches your channel. Saving this requests browser permission for that origin — the extension asks for no network access beyond claude.ai until you do.

Feedback carries the message you type plus, if you leave the box ticked, meter diagnostics (version, model, window size, percentage, tokenizer mode, viewport). It never carries conversation text, titles, ids, or the page URL. The panel shows the exact payload before it is sent.

Tokenizer

Token counts come from a port of Claude’s own tokenizer (ctok), which reproduces Anthropic’s count_tokens exactly — verified against 5,278 reference documents covering 501 natural languages and 22 programming languages. There is nothing to calibrate.

Earlier versions estimated with OpenAI’s o200k_base tokenizer scaled by a hand-tuned multiplier, which was measurably 24–144% off depending on model and content. Those multiplier settings have been removed; if you had customised them, they no longer apply.

Handoff (context chaining)

When the context fills past the threshold, the badge offers to generate a handoff prompt — a self-contained summary to paste into a fresh conversation. It fires below claude.ai's ~85% auto-compaction point so the model still sees the full, uncompacted context when it writes the handoff.

Recommended: 80 (keep below ~85% compaction)
